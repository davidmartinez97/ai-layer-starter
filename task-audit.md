## How to fill it in an hour

1. Write down every recurring task you or your team did last week. Do not filter yet.
2. For each: how often, and where the procedure is written down, if anywhere.
3. Mark "repeatable" only if two different people would do it the same way.
4. The first skill is the task that is daily, written down and repeatable. The second is weekly. Everything else waits.
5. A task that is repeatable but not written down: write the procedure first, in `skills/<name>/SKILL.md`, then it becomes a skill. That writing is the job.
