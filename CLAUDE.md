# Router

Read `company.md` first in every session. Then open only what the task needs, starting from `knowledge/index.md`.

- Company facts live in the linked documents, never in copies. Fetch a document by its exact link.
- Skills live in `skills/<name>/SKILL.md`. A `dev` skill runs only when called by name; a `main` skill runs on its trigger phrases.
- What each connected tool may read and write is in `connections.md`. Start read-only.
- Before saving, publishing or sending anything, run the checklist in `gate.md`.
- If a fact is in neither this folder nor a linked document, ask. Do not invent.
